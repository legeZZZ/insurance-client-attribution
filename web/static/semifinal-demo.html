初赛方案正文：双线归因与结论门禁

初赛基线

初赛解决的问题是：当 UI 改版或经营指标发生变化时，系统能把“实验造成的影响”和“暂时无法解释的变化”分开，并且不在缺少随机化时伪造因果结论。

一句话：A 线用 AB Test 判断“我们改的东西有没有影响指标”；B 线用持续对照和变更账本判断“还有多少变化没有被已知事实解释”。

输入数据

实验输入是用户或曝光级随机化记录：subject_id、treatment/control、clicks、impressions、日期、渠道、设备和版本。经营输入是按日聚合的 control/treated 指标、已登记变更、实验读数和外部事件。

输出对象

A 线输出 Bundle 影响、分群 HTE、可信区间、实际伤害概率和实验决策。B 线输出已登记解释、时间关联、异常阶跃和未知桶。所有输出写入 Claim Ledger，带来源、窗口和证据等级。

状态含义
CAUSAL_READY具备随机化条件，可以进入实验后验。
TEMPORAL_ASSOCIATION时间上对齐，不等于原因。
UNEXPLAINED当前没有证据对上，不能摊派。
A 线：从实验数据到贝叶斯决策

1. 先固定实验口径

定义指标、分子/分母、随机化单元、实验窗口、主指标、护栏和实际损害阈值。没有这些字段，Agent 只能停在描述性输出。

2. 两臂分别建 Beta-Binomial 后验

p_control ~ Beta(a0 + clicks_control, b0 + impressions_control - clicks_control) p_treatment ~ Beta(a0 + clicks_treatment, b0 + impressions_treatment - clicks_treatment) delta = p_treatment - p_control P(harm) = P(delta < -practical_threshold)

贝叶斯在这里做的是量化不确定性：同样的概率差，小样本分群区间更宽；大样本分群区间更窄。它不负责证明随机化是否成立，也不负责寻找外部根因。

3. 分群效应使用概率差尺度收缩

先得到每个分群的 delta_raw 和方差，再使用经验贝叶斯部分池化降低长尾噪声。初赛旧实现的风险是用全局 Logit 增益经 Taylor 展开作为统一目标，低基线分群会被错误放大；该问题在复赛统计修订中统一修正。

4. 输出实验决策

根据后验概率和护栏，输出 SHIP、ROLLBACK_RECOMMENDED、CONTINUE_OBSERVATION 或 EQUIVALENT。系统只提出建议，不自动修改真实流量。

B 线：从持续经营数据到未知桶

1. 建立 persistent control

control 组不接收业务变更，treated 组按线上实际运行。每日计算 gap = treated - control，再减去已有实验读数解释的部分，得到 residual。

gap_t = treated_t - control_t explained_t = registered_change_ATT_t + aligned_external_event_t residual_t = gap_t - explained_t

2. 核对变更登记

登记事实只有“发生过”这一层证据。只有关联的实验读数才能贡献已验证解释；没有实验的登记项最多标记为时间关联。

3. 检测双向异动

对平滑后的 residual 做前后窗口差值，使用 abs(step) 检测。上涨和下降都属于异动，另外保留 direction=up/down 供后续分析。

4. 产生未知桶

末 10 天无法由已登记变更、实验读数和外部事件解释的 residual 进入 UNEXPLAINED。未知桶是待调查量，不是“所有未解释变化的根因”。初赛到这里停止，不负责从未知桶自动发现新因子。

初赛已解决

  • 随机 A/B 的影响估计
  • 分群异质性和不确定性
  • 持续 control 基线
  • 未知桶和拒答边界

  • 登记不等于因果
  • 相关不等于影响
  • 未知不向候选摊派
  • 没有随机化就拒绝因果决策

Step B1：从 control/treated 得到 residual

gap_t = treated_t - control_t explained = registered_experiment_ATT + aligned_external_event residual_t = gap_t - explained_t

登记事实只说明“事件发生过”，有实验读数才可能进入已验证解释；没有对上的部分保留为 UNEXPLAINED，不向候选平均摊派。

Step B2：双向异动切面 复赛升级

在平滑 residual 上计算前后窗口差值，判定条件为 abs(step) >= threshold。上涨和下降都进入异常队列，同时保存 absolute_step 与 direction=up/down。当前 fixture 保留 day 44 附近上行、day 51 附近下行两类异常。

Step B3：Rate-aware 多维 RCA 复赛升级

在 region、channel、version、device 等维度上逐层下钻，比较候选切面和补集。对 rate 指标显式分解：

CTR = Σ share_s × rate_s ΔCTR = rate_change + mix_change + interaction rate_change = Σ share_before × Δrate mix_change = Σ Δshare × rate_before interaction = Σ Δshare × Δrate

三项必须闭合；交互项不再隐含塞入 rate 或 mix。闭合失败输出 DECOMPOSITION_NOT_CLOSED，不继续给出候选优先级。

Step B4：因子三层派生 复赛升级

X_t = rolling_median(raw_factor_t, window=3) Level_t = X_t Velocity_t = X_t - X_(t-1) Acceleration_t = X_t - 2X_(t-1) + X_(t-2)

Level 可能发现“汇率整体升高”，Velocity 可能发现“竞品压力突然增加”，Acceleration 可能发现“汇率变化正在加速”。二阶派生只是增加候选覆盖，不是自动根因。

Step B5：关联搜索和选择防线 复赛升级

本次增强 fixture 固定扫描 M=4 个父因子、D=3 个派生层、S=3 个范围、L=29 个滞后、K=1 个指标，完整网格 N=1044，有效比较 348 次，block bootstrap 199 次。先在 discovery [0,49] 搜索，再在 holdout [50,59] 复核；BH q 值只作辅助，holdout 才是候选晋级主防线。

Step B6：输出什么

输出实际含义下一步
FACTOR_CANDIDATE异常切面与某个可观测因子/派生层具有待调查关联。进入候选库，等待 holdout 或验证。
TEMPORAL_ASSOCIATION事件与异常在时间/范围上对齐。做负对照和准实验，不能写“导致”。
UNEXPLAINED仍没有可用数据入口或匹配证据。保留未知，创建补数任务。

四、统计、知识库和 Agent 的完整边界

Bayesian 复赛修订

两臂 Beta-Binomial 得到概率差后验；cell → group → pooled 全流程在 probability-difference 尺度收缩。Logit 只能作为完整链接函数，不能用全局 Logit Taylor 目标。最终 SE 从最终后验计算。

Factor RAG 复赛升级

检索因子定义、别名、时间范围、证据片段、数值快照、许可证和历史验证模板；不修改后验、不产生根因字符串。

N2 意图层 复赛升级

本地 LLM 只返回 AnalysisIntent。Schema 失败、超时或置信度不足时规则兜底，保留模型版本、规则版本、fallback 原因和工具 trace。

N3 执行层 复赛升级

实验创建、灰度和护栏读取默认 dry-run；护栏超限只输出 PAUSE_RECOMMENDED，不自动回滚、放量或修改生产流量。
