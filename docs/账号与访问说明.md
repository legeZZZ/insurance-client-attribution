# 账号与访问说明

**本系统无需任何账号、注册或外部服务凭证即可完整评审。**

| 项 | 说明 |
|---|---|
| 运行账号 | 无。本地服务与离线页面均不要求登录、不校验身份 |
| 外部 API Key | 不需要。全部演示数据由种子脚本在本地通过真实管线生成（`tools/seed_console_v2.py`） |
| 网络依赖 | 本地运行完全离线可用；控制台 3D 视图的 three.js 已内置本地副本，CDN 不可用时自动回退 2D |
| 数据库 | 内置 SQLite（首次运行自动初始化），无需外部数据库 |
| 云端部署（可选） | 提供 Dockerfile / docker-compose.yml / Procfile / render.yaml，部署后同样无账号门槛；详见 `HTTP_DEPLOY.md` |
| 演示数据 | 全部为脱敏/合成数据，页面与文档中明确标注，不含任何真实客户信息；见 `数据来源与合规说明.md` |

如评审环境完全离线：直接双击 `web/static/final-console-v3.html` 即可离线回放全部六视图与完整技术方案（因子库视图内嵌）。
